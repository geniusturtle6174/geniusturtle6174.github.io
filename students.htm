專題生要求

  • 基本知能
    • 加入前必須已經會寫 Python。
    • 最遲於實際開始參與工作中，要學習與使用 Git 與 PyTorch 等工具。
    • 最遲於專題發表前一年，修習機器學習相關課程及格，或取得我認可之同等實績。
  • 關於題目
    • 題目主要為機器學習在音訊處理或醫療方面的應用。你亦可自行尋找與機器學習應用相關之題目，並與我討論是否合宜。
    • 未經我同意而自行更換方向者，視同放棄找我簽署專題成果報告授權書之權利。
  • 其他說明
    • 預設是每週一次咪聽，唯接近論文或競賽等之截止期限時，很可能會有一週兩次以上之咪聽。
    • 你可能需要自備運算環境與資源，並且不一定會有實驗室位置及研究津貼。

研究生要求

  • 基本知能
    • 加入前必須已經會寫 Python。
    • 最遲於實際開始參與工作中，要學習與使用 Git 與 PyTorch 等工具。
    • 最遲於口試前一年，修習機器學習相關課程及格，或取得我認可之同等實績。
  • 關於題目
    • 題目主要為機器學習在音訊處理或醫療方面的應用。你亦可自行尋找與機器學習應用相關之題目，並與我討論是否合宜。
    • 未經我同意而自行更換方向者，視同放棄找我簽署口試請相關文件之權利。
  • 畢業條件
    • 達成右列三項中之任兩種（已達成兩種者，不得以此為理由拒絕教師之工作要求）：與教師合著論文並投稿至期刊或國際會議（或完成已達教師認定具投稿標準之稿件）、擔任助教表現合格、參與計畫表現合格。
    • 最遲於離校兩週前，完成第一次成果（包含但不限於資料集、程式碼、論文稿件）交接。
  • 其他說明
    • 預設是每週一次咪聽，唯你參與之工作較多時，或接近論文或競賽等之截止期限時，很可能會有一週兩次以上之咪聽。
    • 你可能需要自備運算環境與資源，並且不一定會有實驗室位置及研究津貼。

索取推薦函

  • 索取標準
    • 僅具修課生身分者，需取得總成績 80 分以上，或已結算之成績之 80% 以上（此為最低標準，且達標不代表同意推薦）。
    • 具專題生身分者，須已有相關實績。
    • 具研究生身分者，須在教學助理、計畫參與、論文發表三項中，至少兩項取得教師認可之成果或實績。
  • 推薦方式
    • 你申請的單位若為位於台灣、中國、香港、澳門時，我僅願意協助以正體中文進行推薦。
    • 若申請單位可能接受多種收件管道時，應依右列先後順序找我進行：網頁表單填寫、email 逕寄申請單位、紙本公開推荐函簽名後交申請人寄送、推荐函簽名彌封後交申請人寄送。
    • 承上，若須紙本及信封時，由申請人準備。
  • 其他說明
    • 於我擔任專任教師之學校，具學籍之未畢業學生，我僅協助推薦升學（如大學生申請碩士班、碩士生申請博士班）或就業。
    • 找我推薦時，可以直接先附上一份草稿；但請注意
      • 草稿中只能寫我會直接知道的事實。
      • 除非你能說明自己不具有台灣、中國、香港、澳門之身分證或護照，否則來訊及草稿應使用正體中文。
    • 我可能會要求你以 email 或其他指定之通訊管道，進行相關討論。
    • 希望索取推薦函者，應盡可能的提早告知；若距離截止期限太近才告訴我，我可能會將此狀況納入推薦函內容之考量。
